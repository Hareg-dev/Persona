# Roadmap

## V1: Chat Research Core

Goal:
Build the first clean chat backend with a supervised research flow.

Scope:

- create chat sessions and messages
- route model requests
- ingest URLs and PDFs
- retrieve evidence from Qdrant
- return structured analysis in chat

## V2: Strong Retrieval

Goal:
Make the assistant reliable on public websites and stored documents.

Scope:

- site page extraction
- site crawling rules
- content chunking
- metadata filters
- better source ranking

## V3: Multi-Agent Supervision

Goal:
Split work into specialized nodes with clear control.

Scope:

- planner
- researcher
- analyst
- writer
- supervisor

## V4: Long-Running Assistant

Goal:
Support ongoing research and monitoring through your journey.

Scope:

- tracked topics
- recurring analysis jobs
- monitored vendors and markets
- daily or weekly intelligence updates
